# Antigravity Instructions for CPS Academy Portal

Always read and strictly follow [AGENTS.md](../../AGENTS.md) in the project root before inspecting or modifying code.

Key constraints:
- AGENTS.md is the canonical architecture and developer handoff document.
- Prioritize autonomy over ceremony: act directly on minor/routine edits; propose a short plan before non-trivial multi-file changes or architecture shifts.
- Never refactor existing working code unless explicitly asked.
- Stop and report when tests fail; do not improvise.
- Ask before running commands that alter dependencies, install packages, or change files outside the agreed plan.
- Never expose private data, credentials, or historical contribution ledgers.
