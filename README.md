# CPS Academy Hub prototype

A private, mobile-first prototype of the Clinical Problem Solvers Academy operating hub.

## Prototype scope

- Morning Reports and VMR readiness
- Member directory and leadership overview
- Podcast workflow
- Conferences and research tracking
- Schema review pipeline
- Important links directory
- Explicit path to a later, permissioned Google Sheets/API integration

All displayed Academy content is realistic sample data. No live Academy system is connected or modified.
